::: important 运行环境  
运行环境: ==.NET Core 8.0 LTS=={.important}  

(一般系统都不自带此环境，请确保您安装成功了)

<LinkCard title="下载 .NET Core 8.0 (x64)" icon="download" href="https://dotnet.microsoft.com/zh-cn/download/dotnet/thank-you/sdk-8.0.416-windows-x64-installer" description="一般的Windows用户都应该下载这个版本。" />

<LinkCard title="下载 .NET Core 8.0 (arm64)" icon="download" href="https://dotnet.microsoft.com/zh-cn/download/dotnet/thank-you/sdk-8.0.416-windows-arm64-installer" description="如果您使用的Windows系统是arm版本的，请下载此版本。" />

**不建议将MSLX放置于磁盘根目录或C盘某些特殊目录（如临时目录或需要管理员权限的目录），否则后果自负！**

**建议在使用MSLX时给软件所处目录添加至杀毒软件信任区中，或在杀软提示时及时添加信任，防止误杀**。

:::

在确定安装好 ==运行环境== 后，直接启动`MSLX.Daemon`软件即可。

如果出现闪退，那么就还是运行环境没有安装好。
